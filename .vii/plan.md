## Repo survey
- Next.js 15.5 App Router; the whole site is one client shell, `src/components/shell/VSCodeShell.tsx` (368 lines), styled by `shell.module.css`.
- The tab bar is `role="tablist"` with roving `tabIndex` but no key handler, so only the active tab is reachable and Enter does nothing.
- Fonts: `@import` of Google Fonts at the top of `globals.css`; `--font-mono` / `--font-serif` tokens name the families directly; canvas visualizations hardcode `"IBM Plex Mono"` in `panels/math/shared.ts`.
- Motion: CSS loops (pulse, blink, cursor, hero glow) plus three `requestAnimationFrame` canvases; no reduced-motion handling outside the blog reading rail.
- No test framework and no CI workflow. `playwright` is already a devDependency; verification today is `npm run build`, `npm run lint`, `npm run check:md`.

## Risk surface
- Tab key handler fights the crawlable `<a>` inside each tab — mitigation: links stay `tabIndex=-1`, handler only on the `li`.
- `next/font` renames the families; anything naming "IBM Plex" directly would fall back — mitigation: the only direct use (canvas) reads the variable.
- Global reduced-motion rule also stops the drawer slide and chat fade — acceptable: they become instant.
- Bigger mobile tabs/text could overflow the tab strip — mitigation: it already scrolls horizontally; check at 390px.

## Rollback
Each PR is one squash-free merge commit on `develop` and later on `main`. `git revert -m 1 <merge sha>` on `develop`, PR to `main`, redeploy (Vercel deploys `main` in ~2 minutes). Or promote the previous Vercel deployment instantly.
